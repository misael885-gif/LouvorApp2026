# Publicar Gratis

## Melhor caminho sem gastar nada

Use um destes dois:

1. `Cloudflare Pages`
2. `GitHub Pages`

Os dois servem o app em `https://`, o que permite:

- instalar no Windows como app web
- instalar no Android
- usar no iPhone pela Tela de Inicio
- registrar o `service worker`

## Opcao 1: Cloudflare Pages

Mais simples para este projeto.

1. Abra o painel do `Cloudflare Pages`.
2. Crie um projeto novo.
3. Use `Direct Upload` ou conecte um repositório.
4. Envie esta pasta inteira.
5. Depois de publicado, abra o link final no navegador.

## Opcao 2: GitHub Pages

1. Crie um repositório no GitHub.
2. Envie os arquivos deste projeto.
3. Ative `GitHub Pages` nas configuracoes.
4. Publique a branch principal.
5. Abra a URL publicada.

## Como instalar depois de publicar

### Windows

1. Abra o app no `Microsoft Edge` ou `Chrome`.
2. Procure a opcao `Instalar aplicativo`.
3. Confirme a instalacao.

### Android

1. Abra o link publicado no `Chrome`.
2. Toque em `Instalar app` ou `Adicionar a tela inicial`.
3. Confirme.

### iPhone

1. Abra o link publicado no `Safari`.
2. Toque em `Compartilhar`.
3. Toque em `Adicionar a Tela de Inicio`.
